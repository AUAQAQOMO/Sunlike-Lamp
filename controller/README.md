# Sunlike 无线旋钮控制器（ESP32-C3）

独立工程，与台灯本体通过 **ESP-NOW** 配对通信。台灯插电、控制器电池供电，
两者无需同一路由器，也不占用 WiFi。

## 一、硬件要点

| 项目 | 说明 |
|---|---|
| 主控 | ESP32-C3-MINI-1U-H4（外置天线，注意天线连接） |
| 供电 | USB-C 5V（**只供电，DP/DM 未接 MCU**）→ TP4056 充电 → 1S 锂电 → SW3 → ME6211 LDO 3.3V |
| 旋钮 | EC11：**GPIO5 = A 相，GPIO6 = B 相，GPIO4 = 按键** |
| 指示灯 | **无**。配对/发送是否成功只能靠"台灯有没有反应"判断 |

## 二、烧录

板上 USB-C 不能传数据，必须走 **UART0**（H1 排针 `VCC / RXD0 / TXD0 / GND`）：

```bash
cd controller
pio run -t upload                       # 需要先按住 BOOT 再点 RST 进下载模式
pio device monitor
```

首次上电串口应看到：

```
 Sunlike 无线旋钮  v1.0.0
[BOOT] 未配对（扫描中） / 信道 1 / 唤醒来源 上电 / FreeHeap=...
[NOW] 未配对，开始扫描信道
```

## 三、配对流程

1. **台灯先上电并连上 WiFi**（台灯启动日志会打印 `[NOW] 就绪，信道 x，等待配对`）；
2. 控制器上电后自动在 1~13 信道轮询广播，**最多约 10 秒**配上台灯；
3. 成功后控制器日志出现 `[NOW] 配对成功：XX:XX:...`，此后转旋钮台灯应立即响应；
4. 配对信息写入双方 NVS，**断电重启不需要重新配对**。

**重新配对**：先长按台灯 5 秒（闪 3 下后重启，会清掉旧配对），
再长按控制器 5 秒（清除自己的配对并重启），控制器会自动重新扫描。

> 台灯已配对时会忽略其他控制器的配对请求，这是安全设计，不是故障。

## 四、日常使用（与台灯本体一致）

| 操作 | 行为 |
|---|---|
| 旋转 | 调亮度（1% 步进，暗端自动放大） |
| 按住 + 旋转 | 调色温（2% 步进） |
| 单击 | 开 / 关 |
| 长按 5s | 清除配对并重启 |

灯灭时转动旋钮会先点亮（与本体行为一致）。

## 五、工作方式

控制器**不保存灯光状态**，只发增量命令：

```
CMD_NUDGE_BRIGHT  delta   →  台灯调 nudgeBrightness(delta)
CMD_NUDGE_CCT     delta   →  台灯调 nudgeCct(delta)
CMD_TOGGLE                →  台灯翻转开关
CMD_PING                  →  台灯回 ACK（带自己的 WiFi 信道）
```

好处：手机/小爱随时改灯都不会和控制器打架，不会出现"转一下跳回旧值"。

### 信道自适应

台灯的 ESP-NOW 工作在它所连路由器的信道上。控制器：

- 配对时扫描 1~13 找台灯，并记录台灯上报的信道；
- 每 30 秒发一次 PING，从 ACK 里读台灯当前信道；
- 路由器重启换了信道 → ACK 里的信道变了，控制器自动跟随；
- 连续 2 次 PING 无应答 → 回到扫描（**只认原配对的 MAC**，不会误配邻居家的灯）。

## 六、休眠与续航

无操作 **60 秒**后进入 `light sleep`，三个 EC11 引脚任意一个被拉低即唤醒（约 1ms），
唤醒后自动重建 ESP-NOW。

> **为什么不用 deep sleep**：C3 的深睡只能靠 ext1 唤醒，而 IDF 4.4 的 ext1 仅支持
> `ALL_LOW` / `ANY_HIGH`；EC11 是"上拉、动作拉低"，三个脚永远不可能同时为低，
> 深睡就再也醒不过来。light sleep 支持任意引脚低电平唤醒，代价是待机电流高一些
> （0.5mA 量级，1000mAh 电池约两三个月）。

**已知副作用**：唤醒瞬间正在转的那一格可能丢失（芯片要先醒来），再转一下就正常。

## 七、需要实测调整的两处

| 现象 | 改哪里 |
|---|---|
| 顺时针变成调暗 / 调暖（A/B 引脚与台灯正好互换） | `config.h` 的 `ENC_DIR` 改成 `-1` |
| 转两格才动一档 | `config.h` 的 `ENC_TICKS_PER_DETENT` 改成 `2` |

## 九、配对不上时的排查顺序

1. 台灯串口是否打印 `[NOW] 就绪，信道 x`（没打印说明 ESP-NOW 没起来）；
2. 台灯是否 `已配对` 到旧控制器（需要先长按 5s 清除）；
3. 两台设备距离是否过近（<20cm 时 ESP-NOW 可能饱和），拉开半米再试；
4. 控制器是否一直打印 `配对成功` 又立刻丢失——通常是台灯 WiFi 信道在变（路由器 MST/负载均衡），
   等一分钟让控制器跟随一次即可。
